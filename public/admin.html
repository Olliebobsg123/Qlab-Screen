Check QLab

Finds out what your QLab version and passcode support, so there are no surprises in the show. The check only reads from QLab, unless you also pick a cue to test with: that cue plays for a few seconds (use a quiet or silent audio cue) to test start-from, skipping, pause and stop.

    Departments

    Each department logs in at /login.html and controls only its own cues

    Choose what each department owns: cue types (e.g. Audio + Mic → Sound, Video + Camera + Text → Video, Light → Lighting), and/or whole cue lists, cue colours or name prefixes such as LX. A cue belongs to a department if it matches any of its types, colours or prefixes; if you also tick cue lists, only cues in those lists count. Departments need QLab control switched on (Control & API tab).

    Run automatically on this Mac
    
        
    
        
    
          Installed as a service, QLab Connect starts when the Mac logs in, restarts itself if it ever stops,
          and keeps the Mac awake. In Terminal, in the QLab Connect folder:
        
    
        
    npm run mac:install     # install and start (asks for an admin password the first time)
npm run mac:restart     # after updating with git pull
npm run mac:status      # is it running?
npm run mac:logs        # watch what it's doing
npm run mac:uninstall   # stop and remove it
    
        
    For a show Mac, also turn on automatic login (System Settings → Users & Groups) and set it to start up automatically after a power failure (System Settings → Energy).
