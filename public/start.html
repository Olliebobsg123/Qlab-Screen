Setting up a show

  1. Connect to QLabAdmin → QLab: enter the QLab Mac's address and passcode, and pick the workspace.
    Open
  2. Allow cue controlAdmin → Control & API: switch on control so departments, the Control page and MIDI can fire cues.
    Open
  3. Set the Stage Manager passwordAdmin → Departments: the Stage Manager department is ready, it just needs a password.
    Open
  4. Add departmentsAdmin → Departments: give each team a password and the cue types it runs.
    Open
  5. Save your setupAdmin → Backup: download a .qlabconnect file so you can restore everything later.
    Open
